# 大家來找茬（單張對比圖自動鏡像版）

純前端靜態網頁架構（HTML + CSS + Vanilla JS），支援直接上傳**單張左右並排對比圖**，無需手動裁切，可直接部署至 **GitHub** 與 **Vercel**。

## 核心工作流
1. **單圖上傳與自動左右鏡像**：
   - 在後台只需上傳 **1 張**包含左右兩幅畫面的對比圖。
   - 只要在圖片的**左半邊或右半邊**按住滑鼠拖曳畫圓，系統會自動透過水平鏡像（`x ± 0.5`）同步產生另一半邊的感應區（後台以綠色虛線圓圈即時預覽）。
   - 玩家遊玩時點擊左側或右側任何一邊的對應位置皆可正確得分並同步畫圈。
2. **完整功能保留**：
   - 支援多關卡連續挑戰、每關獨立／全程總時間倒數計時器、後台管理密碼鎖（預設 `1234`）、點擊次數限制及各不同點獨立計分。
   - 支援匯出 `game-config.json` 覆蓋專案根目錄檔案並推送至 GitHub / Vercel 發佈。
